חיבור Firebase

הגדר חיבור לסנכרון בזמן אמת בין כל המשתמשים

📋 הוראות הגדרה:
1. פתח console.firebase.google.com
2. צור פרויקט חדש (שם חופשי)
3. לחץ "Realtime Database" → "צור מסד נתונים" → בחר Test mode
4. לחץ ⚙️ Project Settings → "הוסף אפליקציית Web" → העתק את ה-config
